# Benchmark Results

This directory stores benchmark artifacts generated by the KANX benchmark suite.

## Files

- `real_world_results.json` — real-world benchmark results for California Housing,
  Concrete Compressive Strength, and Energy Efficiency datasets.
- `results.md` — synthetic benchmark results generated by `benchmarks/compare_mlp.py`.
- `.gitkeep` — keeps this directory in version control when no results are present.

## How to regenerate

Run the full benchmark suite with:

```bash
bash scripts/run_benchmarks.sh
```

Or run a single benchmark manually:

```bash
python benchmarks/compare_mlp.py --long
python benchmarks/real_world.py
python benchmarks/real_world.py --device cuda   # PyTorch KAN + MLP in a subprocess
```
